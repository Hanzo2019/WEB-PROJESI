# 🛠️ DIY (Kendin Yap) Platformu

Bu proje, kullanıcıların üye olup kendi DIY (Kendin Yap) projelerini paylaşabileceği ve diğer kullanıcıların hazırladığı projelerin yapılış adımlarını inceleyebileceği interaktif bir web demosu olarak tasarlanmıştır.

## 🚀 Proje Adımları ve Yol Haritası
1. **Planlama ve Klasörleme:** Proje yapısı ve mimarisi belirlendi.
2. **Arayüz Tasarımı:** HTML, CSS ve JavaScript kullanılarak kullanıcı girişi, keşif ve proje ekleme sayfaları kurgulanıyor.
3. **Versiyon Kontrolü:** Proje GitHub üzerinde repolandı ve kod takibi sağlandı.
